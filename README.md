# maozi\-cloud\-parent

> 基于 Spring Cloud Alibaba \+ Dubbo 的一站式分布式解决方案开源封装，内置分布式应用开发所需全套组件，统一团队代码风格，保障代码质量，让开发者专注业务逻辑，实现高效快速开发。
>
>

## ✨ 核心特性

- **全链路灰度发布** — 精细化流量管控，平滑版本迭代

- **全链路完整日志** — 分布式追踪，问题定位一目了然

- **本地高效开发模式** — 一键启动，贴近生产的本地调试体验

- **入参出参映射数据源条件查询** — 声明式查询，减少样板代码

- **分布式锁** — 开箱即用的分布式并发控制

- **服务监控** — 全方位运行时状态观测

- **领域模型设计** — DDD 分层架构，业务边界清晰

- **微服务与单体无缝切换** — 一套代码，灵活部署形态

- **全链路回归测试** — 自动化质量保障体系

- **全链路压力测试** — 性能瓶颈提前发现

- **完整可观测监控** — Metrics / Tracing / Logging 三位一体
