# 本地业务服务容器化部署

## 部署前准备

1. 进入基础镜像[目录](https://github.com/1095071913/maozi-cloud-parent/tree/release/maozi-cloud-script/maozi-cloud-image/maozi-cloud-base-jdk-image)执行
   ```
   docker buildx build -f Dockerfile -t maozi-cloud-base-jdk:1.0.0 .
   ```
2. 进入业务基础镜像[目录](https://github.com/1095071913/maozi-cloud-parent/tree/release/maozi-cloud-script/maozi-cloud-image/maozi-cloud-business-jdk-image)执行
   ```
   docker buildx build -f Dockerfile -t maozi-cloud-business-jdk:1.0.0 .
   ```
3. 该[文件](https://github.com/1095071913/maozi-cloud-parent/blob/release/maozi-cloud-script/maozi-cloud-image/maozi-cloud-services.json)中的`"dubbo_ip_to_registry": "192.168.124.2"`修改为物理机IP,该配置作用为物理机的业务服务能访问到容器内的业务服务，若确定物理机的业务服务不会调用到容器内的业务服务可以直接注释掉`"dubbo_ip_to_registry": "192.168.124.2"`和`"dubbo_flag": "-DDUBBO_IP_TO_REGISTRY=${DUBBO_IP_TO_REGISTRY}"`
4. 该[文件](https://github.com/1095071913/maozi-cloud-parent/blob/release/maozi-cloud-script/maozi-cloud-docker/maozi-cloud-services-docker/docker-compose.yml)中所有的`/Users/maozi/Desktop/maozi-cloud-logs`修改为该[文件](https://github.com/1095071913/maozi-cloud-parent/blob/release/maozi-cloud-script/maozi-cloud-docker/maozi-cloud-basics-docker/docker-compose.yml)中的原值为`/Users/maozi/Desktop/maozi-cloud-logs`修改后的新值一致

## 全量部署

1. 单体服务[bat脚本](https://github.com/1095071913/maozi-cloud-parent/blob/release/maozi-cloud-script/maozi-cloud-build/maozi-cloud-bat/maozi-cloud-build-all-monomer.bat)执行
2. 单体服务[shell脚本](https://github.com/1095071913/maozi-cloud-parent/blob/release/maozi-cloud-script/maozi-cloud-build/maozi-cloud-shell/maozi-cloud-build-all-monomer.sh)执行
3. 微服务[bat脚本](https://github.com/1095071913/maozi-cloud-parent/blob/release/maozi-cloud-script/maozi-cloud-build/maozi-cloud-bat/maozi-cloud-build-all-distributed-force.bat)执行
4. 微服务[shell脚本](https://github.com/1095071913/maozi-cloud-parent/blob/release/maozi-cloud-script/maozi-cloud-build/maozi-cloud-shell/maozi-cloud-build-all-distributed-force.sh)执行
